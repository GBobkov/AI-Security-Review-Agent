---
title: B506 unsafe YAML loading and CWE-502
cwe: CWE-502
source_url: https://cwe.mitre.org/data/definitions/502.html
---
Bandit B506 reports use of a YAML loader that can construct arbitrary Python objects. This is a form of CWE-502: deserializing untrusted data without sufficient control over the resulting types or behavior. YAML tags supported by general-purpose PyYAML loaders may resolve Python names or invoke object construction. A document that looks like configuration can therefore cause behavior far beyond creating strings, numbers, lists, and mappings.

For ordinary configuration, use `yaml.safe_load` or explicitly select `yaml.SafeLoader`. Safe loading restricts construction to basic data types, but the application must still validate the resulting structure, required keys, value ranges, and maximum size. Treat repository files, uploaded documents, cached data, and messages as untrusted unless their integrity and origin are enforced.

If custom YAML tags are an actual requirement, register a minimal constructor for each expected tag on a restricted loader. Do not restore a broad object loader just to support one type. Resource exhaustion is a separate concern: limit input size and processing resources when an attacker can supply complex documents. When reviewing a B506 finding, check which PyYAML version is installed and identify the exact loader passed through wrappers; a safe-looking helper may delegate to an unsafe default elsewhere.
